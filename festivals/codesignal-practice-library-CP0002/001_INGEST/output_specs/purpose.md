# Purpose and outcome

Make this simulator useful for repeated preparation, not one File Storage run.
A user can choose an exercise, practice, submit, inspect previous work, and try
again without deleting folders or waiting for an old clock to expire.

Done means multiple complete original exercises are selectable, unlimited
attempts are supported, explicit restart preserves old work, and review/history
survive reloads and server restarts. Acceptance must exercise persistence and
negative paths, not just render new screens.

This festival is in requirements intake. No implementation is claimed complete.
